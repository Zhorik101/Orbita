# Орбита для Android

Установочное Android-приложение с локально упакованным интерфейсом. Android 8.0 и новее. Java Activity + Android System WebView, без сторонних библиотек и разрешения на доступ в интернет. Внешние ссылки открываются в браузере.

Расписание демонстрационное, не синхронизировано с РТУ МИРЭА. Заметки, задачи, группа и тема хранятся локально в WebView. Данные сайта автоматически в приложение не переносятся. При удалении приложения данные удаляются.

Светлая и тёмная темы доступны кнопкой в верхней панели и в разделе «Оформление». При первом запуске используется тема системы.

## Сборка

Нужны JDK 17+, Gradle 8.10.2, Android SDK Platform 35 и Build Tools 35.0.0. Настрой `ANDROID_HOME`, `ANDROID_BUILD_TOOLS` и `ORBITA_KEYSTORE`, затем запусти `bash build.sh`. Для Gradle вне PATH укажи `ORBITA_GRADLE`. Хранилище ключа должно содержать alias `orbita`, пароль запрашивается при подписи.

Обновления должны иметь тот же application ID, подпись и увеличенный versionCode. Исходники интерфейса находятся в assets/.

## Версия 1.1

Три настоящих Android App Widgets: ближайшая пара, расписание на день, незавершённые задачи. Добавление через «Оформление» или меню виджетов лаунчера. Размеры можно менять. Тема виджетов соответствует теме приложения. Есть кнопка обновления; автоматическое обновление Android планирует примерно раз в 30 минут и может откладывать.

Произвольная группа вводится вручную. Последняя группа и полное состояние сохраняются синхронно в SharedPreferences Android; старые данные WebView автоматически переносятся при первом запуске обновления. Следующая выбранная группа заменяет предыдущую и используется при последующих запусках. Ввод группы не подключает настоящее расписание. Ключ подписи тот же, versionCode увеличен: обновление устанавливается поверх 1.0 без удаления данных. Ключ подписи хранится отдельно от архива исходников.

Три блока главного экрана можно независимо скрыть в разделе «Оформление».

## Версия 1.2 — карточки внутри приложения

Главная → «Изменить». В режиме редактирования карточки можно перетаскивать за ⠿, двигать стрелками, сжимать/расширять и убирать. Через «Добавить карточку» доступны ближайшая пара, расписание, сводка пар, перерыв, задачи и личная заметка. «Готово» сохраняет раскладку в Android, «Отмена» отменяет изменения раскладки. Пустой главный экран поддерживается; из каталога можно восстановить стандартный набор. Изменения других данных (задач, группы и заметок) сохраняются отдельно. Скрытие карточки не удаляет её данные.

Расписание в компактном размере сохраняет полную ширину для читаемости и ограничивает высоту прокручиваемого списка. Остальные карточки занимают половину или полную ширину мобильного экрана.

Проверки через jsdom покрывают перенос данных версии 1.1, добавление/скрытие/порядок/размер карточек, pointer drag, отмену, пустой экран, восстановление, повторный запуск и редактирование задач/группы при скрытых карточках. На физическом телефоне эта версия ещё не проверена.

## Версия 1.3 — экран «Пары» по визуальному референсу

Отдельный экран расписания с чёрным фоном, голубыми акцентами, крупными карточками, индикаторами занятий, текущим временем для сегодняшнего дня и переключателями дня, недели и месяца. Учебная неделя отсчитывается от недели начала семестра (сентябрь/февраль). Поиск работает по предмету, преподавателю и аудитории; фильтры — по типу занятия. Заметки привязаны к дате, группе и занятию. Экспорт создаёт ICS-файл выбранной недели с явной пометкой ДЕМО; Android предлагает системный выбор места сохранения без разрешения на всё хранилище.

Нижняя навигация: Главная, Пары, Кампус, Карточки, Профиль. Главная сохраняет редактор карточек 1.2. Группа и ранее сохранённые данные остаются на месте. На первом запуске 1.3 включается чёрная тема референса; затем выбор пользователя сохраняется.

Все занятия по-прежнему демонстрационные: выбор группы не загружает расписание университета. Адрес кампуса открывается во внешнем приложении карт. Проверены DOM-логика, поиск, фильтры, три режима календаря, экспорт ICS, заметки, группа и редактор карточек. Физическое Android-устройство и визуальная проверка в браузере недоступны.

## Версия 1.4 — настройки оформления

Нижняя навигация содержит только иконки; доступные названия остаются в aria-label. Четвёртая вкладка открывает задачи. Редактор карточек доступен на главной и в настройках.

Настройки переработаны: учебная группа, готовые темы с миниатюрами, отдельный раздел «Своя тема», настройки главного экрана и компактного расписания. Своя тема содержит выбор акцента и фона через цветовую палитру или HEX; есть быстрые цвета, локальное превью, отмена и применение. Превью не меняет сохранённое оформление. Шаблоны и своя тема переключаются независимо: выбор шаблона сохраняет ранее выбранные ручные цвета для повторного применения.

Фон, карточки, выбранные элементы, кнопки и текст используют общие цветовые переменные. Текст и цвет текста на акценте выбираются автоматически по контрасту; Android получает цвет системных панелей. Состояние сохраняется в существующем хранилище без сброса группы, задач, заметок и раскладки.

DOM-проверки покрывают оба режима темы, ручной ввод и валидацию цвета, отмену, повторный запуск, переключение шаблонов, контраст основного текста, навигацию и регрессии расписания/карточек. На реальном телефоне версия не проверена.

## Версия 1.5 — мини-приложения

Четвёртая вкладка — каталог мини-приложений с иконкой из четырёх плиток и без подписи в нижней навигации. Плитки: карты (адрес кампуса и открытие онлайн-карты во внешнем приложении), заметки, группы, задачи, редактор карточек и месячный календарь.

Заметки: создание, редактирование, поиск и удаление с подтверждением; записи сохраняются в существующем локальном хранилище. Заметка главного экрана также доступна в списке и синхронизирована с карточкой главной. Группы: выбор из сохранённых, добавление своей и избранные. Это не загружает реальное расписание. Задачи используют прежний список без потери данных. Навигационная кнопка «Назад» и Android Back возвращают из вложенных инструментов в каталог.

Проверены все плитки, переходы, работа заметок, отмена удаления, поиск, сохранение при повторных запусках, группы и избранные, задачи, редактор и календарь, а также сохранение настроек цвета. APK подписан прежним ключом для установки поверх 1.4. На физическом устройстве версия не проверена.

## Версия 1.6 — жесты, анимации и исправления темы

В редакторе главного экрана кнопка изменения размера убрана. Потяните нижний правый угол карточки: ширина привязывается к сетке, высота меняется в пределах 140–640 пикселей. Расписание сохраняет полную ширину для читаемости. «Готово» сохраняет размеры; «Отмена» возвращает прежнюю раскладку. Отмена указательного жеста также восстанавливает размер. Ручка поддерживает стрелки клавиатуры.

Свайпы: на списке пар — соседний день, на полосе дат — соседняя неделя; в режимах недели и месяца перелистывается соответствующий период. Горизонтальный жест отличается от вертикальной прокрутки; на краях месяцев дата ограничивается последним днём нового месяца. Выбор срока задачи использует отдельный календарь в цветах приложения со свайпами, стрелками, кнопками «Сегодня», «Без срока», «Отмена» и «Выбрать», без системного бело-зелёного диалога. Android Back закрывает верхний открытый диалог.

Добавлены переходы экранов, календаря, карточек и диалогов с учётом системной настройки уменьшения движения. Исправлены цвет применения своей темы и активной нижней вкладки, добавлен отступ под плавающую панель. Настройки показывают актуальную версию.

Проверены жесты, привязка ширины и высоты, сохранение/отмена размеров, свайпы и границы месяцев, сохранение срока задачи, отключение анимаций, а также регрессии группы, темы, мини-приложений и раскладки. Сборка и подпись APK проверены. На физическом Android-устройстве и визуально в браузере не проверялось.

## Версия 1.7 — общий стиль календаря и прозрачные системные области

Оформление календаря распространено на настройки, мини-приложения, карточки, поля ввода, переключатели и диалоги. Общие радиусы, отступы, акцентные заголовки и цвета используют выбранную тему. Диалоговые заголовки оформляются в единой структуре, сохраняя существующие обработчики ввода. Нижняя навигация полупрозрачная с backdrop blur.

Android рисует приложение под прозрачными системными панелями; системные часы и значки остаются настоящими и видимыми. На Android 11+ используется setDecorFitsSystemWindows(false), на старых версиях — совместимые layout-флаги. Вырез экрана, верхний/нижний системные отступы и состояние клавиатуры передаются в CSS. Цвет значков подбирается под выбранную тему без возврата сплошного цвета status bar. Принудительное системное затемнение панелей отключено на поддерживаемых версиях.

Слой над контентом в области status bar постепенно размывает прокручиваемый контент и добавляет полупрозрачную подложку в цвет фона. WebView должен поддерживать CSS backdrop-filter; предусмотрена полупрозрачная градиентная подложка при отсутствии поддержки. Верхние и нижние отступы учитывают реальные системные панели, плавающая навигация располагается над нижним inset.

Проверены инициализация и обновления insets, зависимость blur от scroll, цвета стеклянных слоёв в своей теме, поведение клавиатуры, новые диалоги группы/заметок/задач и вложенный выбор даты. Android-код скомпилирован, APK подписан. Визуальный эффект под системными значками и поведение на физическом телефоне ещё не проверены.

## Версия 1.8 — фон, общий стиль и прямое подключение расписания

Исправлена конкретная причина фона: CSS-переменные, заданные на html, перекрывались переменными классов body. Итоговая палитра теперь устанавливается непосредственно на оба элемента. Проверяется вычисленное свойство фона body. Убраны цветные шапки секций, карточки расписания на главной используют тот же renderer, что вкладка «Пары».

Android запрашивает открытый официальный источник https://schedule-of.mirea.ru напрямую через HTTPS: `/schedule/api/search?match=...&limit=100` и `/schedule/api/ical/{target}/{id}?includeMeta=true`, target 1/2/3 = группа/преподаватель/аудитория. Сетевой мост разрешает только эти запросы к фиксированному хосту, ограничивает объём ответа и таймауты. WebView продолжает блокировать произвольные внешние ресурсы. Добавлено INTERNET-разрешение. В браузерной версии используется fetch с обычными ограничениями CORS.

Форматы запросов и X-META-полей сверены с публичным описанием Wyndace/rtu-mirea-schedule-api. Живые запросы из среды сборки к schedule-of.mirea.ru завершились ошибкой upstream connection timeout/503; основной сайт вернул HTTP 403. Успешное получение реальных занятий не подтверждено. Приложение показывает состояние ошибки, повторную загрузку, официальный источник и время сохранённой копии; демонстрационных пар при ошибке не подставляет.

ical.js 2.2.1 обрабатывает повторы, исключения, перенесённые события и отмены. UTC преобразуется в московское время. Сохраняются до трёх последних календарей; собственная группа отделена от просматриваемого преподавателя/аудитории. В Android-виджетах вместо фиктивных пар используются загруженные занятия своей группы с датой обновления. При отсутствии актуального снимка предлагается открыть приложение.

Проверки на синтетических ответах (не включены в APK) покрывают три типа поиска, выбор и восстановление, повторы/EXDATE/RECURRENCE-ID, время, offline-кэш, отсутствие фиктивных занятий, сохранение своей группы и исправление реального body-фона. APK скомпилирован и подписан прежним ключом. Живое API и Android-устройство ещё требуют проверки.

## 1.33 — команды и СДО

СДО открывается напрямую в браузере: https://online-edu.mirea.ru/. Карточки СДО на главной нет.

Добавлен клиент собственного сервера совместной работы: отдельные учётки, команды, приглашения на 7 дней, общие работы и заметки, проверка версий при конфликте, отмена выполнения общей работы. Личные записи автоматически не загружаются. Токен в Android хранится через AES-GCM и Android Keystore. Клиент принимает только HTTPS, не следует перенаправлениям API и не отправляет токен на сервер из чужого приглашения.

Backend находится отдельно в orbita-backend. Сервер ещё НЕ размещён: для межтелефонной синхронизации нужен публичный HTTPS-адрес и запуск backend по его README. Учётки не симулируются локально. Восстановление пароля, фоновые push команды, вложения и одновременный редактор заметок пока не реализованы. Проверены реальный локальный API с двумя учётками, разграничение доступа, приглашения/отзыв/истечение, конфликты и интерфейс в Chromium. Android Keystore и deep links на физическом телефоне ещё не проверены.

## 1.37 — работы у пары и исполнители

При открытии пары показываются вручную созданные несданные работы по её дисциплине. Добавление из пары подставляет предмет, сохраняет черновик заметки и возвращает к занятию; эти работы видны у следующих занятий по тому же предмету до выполнения. Автоматического получения заданий из СДО нет.

В командах backend 1.1 поддерживает исполнителя и статусы todo/doing/done; клиент проверяет capabilities, использует version для конфликтов и восстанавливает предыдущий статус при отмене выполнения. Требуется разместить или обновить backend: публичного работающего сервера в комплекте нет.

Источник МИРЭА поддерживает типы экзамен/зачёт/консультация, но при разработке живой запрос вернул HTTP 503. Сессия не заполнена примерами: мини-приложение появляется только при наличии реальных событий этих типов в загруженном календаре своей группы. Данные о сессии не объявляются полными. Вход в учётку МИРЭА не используется.

## 1.38 — виджеты рабочего стола

Нативные Android App Widgets перестраиваются при изменении размера: компактные строки, больше записей и подробностей на крупном размере. Ближайшая пара учитывает уже начавшееся занятие до его окончания; полоса показывает прогресс на момент обновления. Задачи показывают только невыполненные работы, отсортированные по сроку. Цвета своей темы поддерживаются, фон слегка прозрачен. Тап открывает соответствующий раздел приложения.

Виджеты используют сохранённый снимок своей группы; кнопка перечитывает локальные данные, не запрашивает сервер. Периодическое обновление задаёт Android (примерно раз в 30 минут, может откладываться). Дата снимка отображается, устаревший день не выдаётся за актуальный. Проверены сборка ресурсов, компиляция, подпись и парсинг времени; размещение и размеры в Samsung One UI на физическом устройстве ещё не проверены.

## 1.39 — действия уведомлений об изменении расписания

Проверка расписания в истории показывает успешный результат и количество новых изменений; при ошибке можно повторить запрос. Завершение запроса не открывает историю повторно, если пользователь ушёл в другое окно. Из каждой записи доступен переход к группе и дате занятия со сбросом фильтров; своя группа не заменяется.

Уведомление содержит действие «Проверить расписание». MainActivity обрабатывает одноразовые маршруты как при холодном запуске, так и через onNewIntent уже открытого приложения; прочитанные параметры Intent удаляются, чтобы история не открывалась повторно при перезагрузке страницы. Канал и доставка уведомлений сохранены. Проверены браузерные сценарии успешного обновления, ошибки/повтора, перехода по дате и ухода из диалога во время запроса, старые проверки группы и истории. Android скомпилирован и подписан тем же ключом. Запуск из системного уведомления на физическом устройстве ещё не проверен.


## Вложения Google Календаря

Для вложений Android OAuth-клиент регистрируется в Google Cloud с пакетом `ru.mirea.orbita` и SHA-1 сертификата подписанной сборки. В проекте включаются Calendar API и Drive API. В режиме Testing пользователи добавляются в Test users. Авторизацию обрабатывает Google Play Services по пакету и сертификату, OAuth-файл и секреты в APK не включаются.

Включи синхронизацию задач с Google Календарём, сохрани задачу со сроком и дождись отправки события в Google. При редактировании задачи можно прикрепить файл до 200 МБ. Он загружается в Диск выбранного аккаунта. Если загрузка прошла, а прикрепление не получилось, при повторе используется уже загруженный файл.
