# СДО МИРЭА в Орбите 2.1

## Проверка доступа

Из облачной среды публичные GET-запросы к главной странице, странице входа, каталогу курсов и точке запуска мобильного сервиса сайта `online-edu.mirea.ru` вернули HTTP 503. Это результат проверки из данной сети. Он не подтверждает наличие или отсутствие Moodle REST, мобильного API, AJAX-служб и не определяет доступность портала на телефоне.

Публичная страница стороннего проекта была доступна. Утверждения об AJAX и мобильном API не подтверждены авторизованной проверкой. Доступа к сессии студента в облачной среде нет. Структура личного списка курсов, заданий, статусов, оценок и файлов не подтверждена. Клиент стороннего проекта в приложение не включён.

## Реализация

- Официальные страницы открываются в системном браузере через существующий механизм Орбиты. Пароль, MFA, сессия, истечение сессии и выход остаются на стороне портала и браузера.
- Каталог хранит ссылки на курсы и элементы курса, которые студент сохранил сам. Допустимы канонические HTTPS-ссылки на официальный хост с числовым ID. Параметры сессии и произвольные адреса исключены.
- Сохранённые курсы и материалы связываются с дисциплиной. При наличии используются ID дисциплины и семестр. Файлы импортируются через Android Storage Access Framework, хранятся в приватной папке и открываются совместимым приложением через FileProvider. Для экспорта используется системный выбор файла.
- Привязка к личным задачам использует стабильный ID материала. JSON-копия содержит ссылки и метаданные. Сами файлы экспортируются отдельно.
- Просмотр официальных разделов курса, условий, файлов и результатов доступен через оригинальные страницы. Автоматическое чтение данных портала и массовое скачивание с сервера требуют подтверждённого источника. Ручной импорт поддерживает выбор нескольких уже полученных документов.

## Приёмка на Android

Проверить вход и MFA в браузере, открытие курса и задания, импорт нескольких сохранённых файлов, повторный импорт, офлайн-открытие, экспорт, удаление локальной копии, привязку курса к предмету и файла к задаче. Проверить восстановление профиля отдельно от восстановления файлов. Проверить сценарий повторного входа и отсутствие данных браузерной сессии в JSON.
